# voice-analysis-dashboard
Interactive dashboard for exploring session-based voice analysis data generated by a custom DAW plugin.

## MVP API Scope

- POST /sessions - create session
- GET /sessions - list sessions
- GET /sessions/{session_id} - get session detail
- DELETE /sessions/{session_id} - delete session (planned)
- POST /sessions/{session_id}/frames - add frame-level analysis data
- GET /sessions/{session_id}/frames - list frame-level analysis data
  - Query params: `from_sec`, `to_sec`
- GET /sessions/{session_id}/summary - get session analysis summary

## Current Implementation

- FastAPI backend with in-memory session storage.
- Session creation automatically assigns `session_id` and `created_at`.
- Frame-level analysis data can be appended to an existing session.
- Frame data can be filtered with `from_sec` and `to_sec`.
- Session summary calculates pitch, intensity, formant averages, and estimated quality scores.
- Data is not persisted yet; restarting the server clears sessions and frames.
